# The Contestability Index — website

Interactive site for the Contestability Index: fifteen pro-contestability obligation categories scored on the law as written across nine jurisdictions, and a de facto pilot for two European markets.

**Status: preliminary.** Figures may change.

This repository holds only the built site: plain HTML, CSS and JavaScript, no dependencies, nothing to install or build before serving. `js/data.js` and `js/world.js` are generated by the project's build scripts (`website/build/`), which are not part of this repository. To update the site, rebuild those two files, commit, and push; GitHub Pages redeploys from `main`.

Asset links in `index.html` carry a `?v=YYYYMMDD` query. Bump it on each release so browsers do not keep an old stylesheet or data file.
